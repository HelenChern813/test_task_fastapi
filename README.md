# FastAPI Products API

Простое REST API для управления товарами, реализованное на FastAPI.

## Функциональность

- Получение списка товаров с пагинацией
- Получение информации о конкретном товаре
- Создание нового товара
- Обновление существующего товара
- Удаление товара

## Технологии

- Python 3.7+
- FastAPI
- Pydantic
- Uvicorn

## Запуск приложения

### Локальный запуск

**Клонирование репозитория:**
   ```bash
   git clone https://github.com/HelenChern813/test_task_fastapi.git
   cd test_task_fastapi
```

**Установите зависимости:**
```bash
pip install -r requirements.txt
```

**Запустите сервер:**
```bash
uvicorn main:app --reload
```

**Документация проекта + тестирование эндпоинтов:**
- Документация API: http://127.0.0.1:8000/docs

- Альтернативная документация: http://127.0.0.1:8000/redoc

---
Проект написан с целью выполнения тестового задания. Представляет собой MVP-реализацию API:
